

# simple javascript calculator project

this is just my basic calculator lab assignment for moringa school built using native html elements and standard vanilla javascript coding. 

it does basic math like addition, subtraction, multiplication, and division, and it saves your math history inside an array list.

## functions included
* simple math functions for add, subtract, multiply, divide
* logic to push calculations into a tracking history array list
* a basic for-loop that prints out the history onto the screen page
* verification steps that prevent app breaking when users leave boxes blank

## testing the app
just download the files to your folder path and double click index.html to run it in your computer browser.
